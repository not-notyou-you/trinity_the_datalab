# Trinity DataLab: Comprehensive Dataset Report Specification

## Document Purpose
This document serves as the authoritative specification for PDF reports generated by Trinity DataLab. Every report produced must conform to this specification in structure, content, visual design, and technical implementation. This specification is the source of truth that Claude Code must implement—any deviation results in reports that do not meet user expectations.

---

## Report Structure Overview

### PDF Format Standards
- **Page Size:** A4 (210mm × 297mm / 8.27" × 11.69")
- **Margins:** 0.75" (19mm) all sides
- **Font:** Helvetica (body), Helvetica-Bold (headings)
- **Font Sizes:** 
  - Title: 24pt
  - Heading 1: 16pt
  - Heading 2: 14pt
  - Body: 11pt
  - Caption/Footer: 9pt
- **Line Spacing:** 1.5
- **Color Mode:** RGB (for screen viewing) or CMYK (for printing)
- **Compression:** Moderate (readable on slow connections)

### 4.1 Fusion Methodology

#### High-Level Strategy
```
MULTI-SOURCE FUSION STRATEGY

Approach:           Temporal Alignment with Interpolation
Primary Method:     Within ±2-hour temporal window
Backup Method:      Cubic spline interpolation (if >±2 hours)
Gap-Fill Limit:     Maximum 10 days forward-fill
Confidence Metric:  Source availability flag (all-sources, 2-of-3, single)

Design Rationale:
  • Sentinel-1 & GPM: Frequent, unpredictable passes
  • MODIS: Regular 8-day composites
  • Solution: Flexible window that adapts to data availability
```

#### Fusion Algorithm Pseudocode
```python
def fuse_records(date, s1_data, modis_data, gpm_data):
    """
    Fuse three independent satellite observations into one record.
    
    Logic:
      1. Search ±2 hours for all available observations
      2. If all three found → confidence = 'complete'
      3. If 2 of 3 found → confidence = 'partial'
      4. If only 1 found → confidence = 'single_source'
      5. If none within ±2 hours:
         - Search ±24 hours
         - If found → apply interpolation
         - If not → gap-fill backward/forward up to 10 days
      6. Return fused record with confidence flag
    """
```
