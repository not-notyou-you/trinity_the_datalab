Hapus lokasi ini?

Lokasi akan dihilangkan dari daftar pilihan.

Dataset yang sudah pernah dibuat dengan lokasi ini tetap bisa dibuka.

Hapus dataset ini?

Semua file yang tersimpan untuk dataset ini akan dihapus total dan tidak bisa dikembalikan.

Batalkan dataset ini?

Proses akan dihentikan dan data sementara (RAW, ALIGNED, DESPECKLED/INDICES/ACCUMULATED) akan dihapus. Data COG dan FUSED yang sudah selesai tetap disimpan.

Kosongkan dataset live?

Semua data yang sudah terkumpul di dataset live akan dihapus. Pemantauan tetap berjalan seperti biasa setelahnya.
